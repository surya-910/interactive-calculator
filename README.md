# Interactive Calculator & Unit Converter

## Project Description
This is a beginner-friendly Python CLI application that performs basic arithmetic operations, currency conversion, and unit conversions.

## Features
- Addition, subtraction, multiplication and division
- Currency conversion
- Kilometers to miles conversion
- Celsius to Fahrenheit conversion
- Input validation using while loops

## Technologies Used
- Python 3
- Python IDLE

## Concepts Covered
- Variables and data types
- Conditional statements
- Loops
- Functions
- User input and validation

## How to Run
1. Download the Python file.
2. Install Python 3.
3. Open the file using Python IDLE.
4. Press F5 to run the program.
